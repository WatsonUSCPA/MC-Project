# 在庫係Bot（Google Chat × Grok）

Google Chat の中で作業者に「新しい生地の写真を送って」と催促し、届いた写真を Grok に読ませて在庫表（Google スプレッドシート）に登録する Bot です。Google Apps Script だけで動き、サーバーは不要です。

## できること

| 場面 | Bot の動き |
|---|---|
| 毎日 10:00 | 「今日入った生地の写真を送ってください」と催促します。入力が残っている生地があれば、その管理番号も伝えます |
| 毎日 17:00 | 今日の登録が0件の人や、入力が残っている人にだけ、もう一度声をかけます |
| 写真が届いたら | Drive に保存し、Grok が色・柄・素材・商品名の案を読み取ります。長さ・保管場所など足りない項目だけを質問します |
| 返事が来たら | 在庫表を更新し、必須項目がそろえば「✅ 登録しました」と返します |
| 間が空いたら | 前回の登録から日数がたつほど、催促の口調が強くなります |

催促の強さは、前回の登録からの日数で変わります（0〜1日: やさしめ / 2〜3日: しっかり / 4日以上: 強め）。

### 作業者が使うコマンド

- `状況` … 今日の登録件数と、入力が残っている生地の一覧
- `あとで` … 今の生地をいったん保留にする（残りは催促されます）
- `続き F-00012` … 保留した生地の入力を再開する
- `キャンセル` … 今の生地の登録を取り消す
- `催促オフ` / `催促オン`
- `ヘルプ`

### 管理者が Bot に指示を出す

- `指示: 今週から幅も必ず聞いて` … Bot のふるまいにルールを追加します。全作業者との会話と催促文に反映されます
- `指示一覧` / `指示クリア`
- 在庫表の「指示」シートを直接編集しても同じように反映されます。1行が1件の指示です

> 普段使っている Grok（grok.com や X のアプリ）の会話は、xAI API とつながっていません。Bot への指示は Google Chat から送るか、「指示」シートに書いてください。

## 在庫表の列

`管理番号 / ステータス / 登録日時 / 更新日時 / 登録者 / 登録者ID / 写真 / 商品名 / 色 / 柄 / 素材 / 幅(cm) / 長さ(m) / 仕入れ値(円) / 保管場所 / メモ`

- ステータスは Bot が自動で切り替えます。必須項目（長さ・保管場所）がそろうまでは「入力中」、そろえば「登録済み」です
- 人が「確認済み」「EC掲載」などに書き換えた行は、Bot が上書きしません
- 列や必須項目は `Config.gs` の `FIELDS` で変えられます

## セットアップ手順

Google Workspace の**管理者権限がなくても**作れます。ただし組織のポリシーで Chat アプリやサービスアカウントキーの作成が禁止されている場合は、管理者に許可を依頼してください。

### 1. Google Cloud プロジェクトを用意する

1. [Google Cloud Console](https://console.cloud.google.com/) で、Workspace のアカウントを使って新しいプロジェクトを作ります
2. 「API とサービス」→「ライブラリ」で **Google Chat API** を有効にします
3. 「OAuth 同意画面」を **内部（Internal）** で作成します
4. 「IAM と管理」→「サービスアカウント」でサービスアカウントを作り、「鍵」→「鍵を追加」→ **JSON** をダウンロードします
   - `iam.disableServiceAccountKeyCreation` のエラーが出る場合は、組織ポリシーでキーの作成が禁止されています。Workspace の管理者に例外を依頼してください
5. プロジェクトの「プロジェクト番号」をメモしておきます

### 2. xAI の API キーを取得する

[console.x.ai](https://console.x.ai/) で API キーを発行し、クレジットを入れておきます。使うモデルは画像入力に対応したものにしてください。初期値は `grok-4` です。モデル名は xAI のドキュメントで最新のものを確認してください。

### 3. Apps Script プロジェクトを作る

1. [script.google.com](https://script.google.com/) で新しいプロジェクトを作ります（名前の例: 在庫係Bot）
2. このフォルダの `.gs` ファイルをすべて同じ名前で作り、中身を貼り付けます
3. 「プロジェクトの設定」で「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェックを入れ、`appsscript.json` の中身を貼り付けます
   - clasp を使う場合は、このフォルダで `clasp create --type standalone` → `clasp push` でも同じです
4. 「プロジェクトの設定」→「Google Cloud Platform（GCP）プロジェクト」→「プロジェクトを変更」で、手順1のプロジェクト番号を入力します
5. 「スクリプト プロパティ」に次の値を追加します

| プロパティ | 値 |
|---|---|
| `XAI_API_KEY` | xAI の API キー |
| `SERVICE_ACCOUNT_KEY` | ダウンロードした JSON ファイルの中身を全部 |
| `ADMIN_EMAILS` | 指示を出せる人のメールアドレス（カンマ区切り） |
| `GROK_MODEL` | （任意）使うモデル名 |

6. エディタで `setup` を選んで実行し、権限を許可します。ログに在庫表と写真フォルダの URL が出ます
7. `testGrok` と `testChatAuth` を実行し、どちらもエラーが出ないことを確認します

### 4. Chat アプリとして登録する

1. Apps Script で「デプロイ」→「デプロイをテスト」を開き、**Head デプロイ ID** をコピーします
2. Cloud Console の「Google Chat API」→「構成」で次のように設定します
   - アプリ名: `在庫係`、アバター URL、説明
   - 「Google Workspace アドオンとして構築」の選択肢が出たら、**オフ**にします（この Bot は従来型の Chat アプリとして作っています）
   - 機能: 「1:1 のメッセージを受信する」をオンにします
   - 接続設定: **Apps Script プロジェクト**を選び、デプロイ ID を貼り付けます
   - 公開設定: 自分と作業者のメールアドレスを指定します
3. 保存します

### 5. 使い始める

1. 作業者が Google Chat で「＋ 新しいチャット」→「アプリを検索」から `在庫係` を探して、1対1のチャットを始めます
   - 1対1のチャットを始めた人が、催促の対象として自動で登録されます（`showSpaces` で確認できます）
2. `testNag` を実行すると、催促がすぐに1回届きます

## 設定を変える

`Config.gs` の `CONFIG` で変えられます。

- `NAG_HOUR` / `FOLLOWUP_HOUR` … 催促の時刻。変えたら `setup` を実行し直してください
- `NAG_WEEKDAYS` … 催促する曜日（0=日 … 6=土）
- `TONE` … Bot の口調
- `FIELDS` … 在庫表の列、必須項目、写真から推定してよい項目か

## 仕組みと制約

- Chat は30秒以内に返事がないとエラー表示になります。そのため写真は「受け取りました」とすぐ返し、時間主導トリガーで非同期に処理します。結果は数十秒〜1分ほどで届きます
- テキストだけのメッセージは、その場で Grok に問い合わせて返事します。Grok の応答が遅いモデルだと30秒を超えることがあるので、速いモデルを選んでください
- 長さ・仕入れ値・保管場所は、作業者が言った値だけを登録します。写真から推測させないようにしています
- 写真と会話の内容は xAI の API に送信されます
- HEIC など JPEG/PNG 以外の画像は、Drive のサムネイルに変換して読ませます。変換できないときは JPEG で送り直してもらいます
